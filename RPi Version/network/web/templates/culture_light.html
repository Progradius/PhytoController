Comment cette valeur est choisie

Le repère retenu est celui dont la fenêtre de validité contient la date consultée. La priorité est stricte : une culture l’emporte sur un espace, qui l’emporte sur toutes les cultures ; à portée égale, un repère portant le stade déclaré passe avant un repère sans stade, puis le repère commencé le plus tard. Aucun repère n’est appliqué avant son début, aucun repère par défaut n’existe et un repère annulé sort de la résolution.

Un repère ne commande rien : il ne change ni les horaires configurés, ni les sorties.
